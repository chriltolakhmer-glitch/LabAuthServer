## Approved Baseline

The Phase 5.1 owner-approved baseline is:

1. Private/controlled source distribution initially; the GitHub repository remains private.
2. Evaluation permits source inspection, architecture/security review, internal proof of concept, internal demo, and isolated non-production testing.
3. Evaluation does not generally authorize production use, commercial service delivery, redistribution, sublicensing, resale, derivative commercial products, competing-product integration, licensing-control bypass, or general source modification. Narrow modification requires separate written authorization.
4. Production licensing is manual vendor contact, requirements review, commercial agreement, authorized offline signed license issuance, controlled delivery, installation, and startup validation.
5. Official build trust uses product version, Git commit SHA, build timestamp, CI evidence, release manifest, artifact filename, SHA-256 checksum, and release owner/operator record.
6. Technical protection remains the Phase 4 signed-license, edition/feature, fail-closed, provenance, and notice model. No DRM expansion is approved.
7. A complete proprietary documentation package is required before external/public source distribution, and professional legal review remains mandatory.
8. No external source-code contributions initially; bug and security reports may be accepted.
9. Public source release is not authorized and requires a separate later approval.
